# On-Chain Meme Platform

A decentralized platform for creating, sharing, and interacting with memes on the blockchain. Built with React, Solidity, and Web3 technologies.

## 🚀 Features

- **Blockchain-Powered Memes**: Create and store memes on the Polygon Amoy testnet
- **Web3 Integration**: Connect with MetaMask for seamless blockchain interactions
- **Decentralized Storage**: Meme data stored securely on-chain
- **Interactive UI**: Modern and responsive user interface built with React and TailwindCSS
- **Smart Contract Backend**: Secure and efficient smart contracts for meme management

## 🛠 Tech Stack

- **Frontend**: React, Vite, TailwindCSS
- **Blockchain**: Solidity, Web3.js, MetaMask
- **Smart Contracts**: OnchainMemeCore.sol, OnchainMemeAmoy.sol
- **Development**: ESLint, PostCSS, Vercel

## 📦 Prerequisites

- Node.js (v14 or later)
- npm or yarn
- MetaMask browser extension
- Test MATIC (for Amoy testnet)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/kuzhanthaivel/on-chain-meme.git
   cd on-chain-meme
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in browser**
   The app should be running at `http://localhost:5173`

## 🔗 Smart Contracts

- **OnchainMemeCore.sol**: Core smart contract for meme management
- **OnchainMemeAmoy.sol**: Contract deployed on Polygon Amoy testnet

## 📝 ABI

The ABI for the smart contracts is located at `src/Components/ABI.json`.

## 🌐 Deployment

The application is configured for deployment on Vercel. Update the `vercel.json` file with your project settings.
